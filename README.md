# Repositorio del Curso — Laboratorios y Ejercicios

Este repositorio reúne los **cuadernos de laboratorio y ejercicios** desarrollados
durante el semestre en el curso. Su objetivo es servir como material de apoyo
para que los estudiantes repasen, practiquen y completen las actividades vistas
en clase.

## Propósito

El repositorio contiene los cuadernos trabajados en las sesiones prácticas,
cubriendo temas como **procesamiento de lenguaje natural**, **representaciones
vectoriales de palabras (Word2Vec, GloVe)** y **selección de características**
con métodos estadísticos y basados en modelos.

Cada cuaderno incluye una parte demostrativa guiada por el docente y una parte
práctica con ejercicios que el estudiante debe resolver de manera autónoma.

## Contenido

- Cuadernos de laboratorio (`.ipynb`) con el código y las explicaciones.
- Ejercicios propuestos para reforzar los conceptos vistos en clase.
- Gráficas y resultados comparativos que acompañan a las actividades.


> Se recomienda ejecutar los cuadernos celda por celda y experimentar con
> los parámetros para comprender mejor el comportamiento de los algoritmos.
